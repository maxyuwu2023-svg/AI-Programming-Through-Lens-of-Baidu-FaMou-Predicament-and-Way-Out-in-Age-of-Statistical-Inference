# 从百度伐谋看AI编程: 统计推断时代的困境与出路
正式 DOI: [https://dl.acm.org/doi/epdf/10.1145/3843777.3844528](https://www.jsjkx.com/CN/10.11896/jsjkx.260400043)
当前，AI编程工具展现出惊人的代码生成能力，但其本质是否等同于人类程序员的“编程”仍存在根本性争议。百度伐谋是一款以“自我演化”为特征的AI编程智能体，其技术实现涉及大模型与并行计算。以百度伐谋为切入点，深入剖析当前AI编程的本质：它并非真正的“编程”，而是“统计推断”，即通过概率生成字符串来模拟写代码的过程。在此基础上，提出“三阶段框架”定位AI编程的当前能力。揭示从“统计推断”到“算法掌握”的根本鸿沟。进一步指出，真正的出路不在于提升统计推断的准确率，而在于回到“基函数理念”，即在代码原子模块可数学描述的前提下，将代码生成从“概率生成字符串”重构为“数学函数的确定性构造”，从根本上消除统计误差，实现从“黑盒猜测”到“白盒构造”的范式跃迁。
